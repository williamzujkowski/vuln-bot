PRIORITY TIER DEFINITIONS
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│ ACT (Immediate Action Required)                                        │
├─────────────────────────────────────────────────────────────────────────┤
│ • Exploitation: ACTIVE (in-the-wild exploitation confirmed)            │
│ • Automatable: YES (can be exploited without human intervention)       │
│ • Technical Impact: TOTAL (complete system compromise possible)        │
│ • Compact Notation: A/Y/T                                              │
│ • Example: CVE-2024-45519 (Zimbra RCE)                                 │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ ATTEND (Scheduled Action Required)                                     │
├─────────────────────────────────────────────────────────────────────────┤
│ • Exploitation: ACTIVE (in-the-wild exploitation confirmed)            │
│ • Automatable: NO *OR* Technical Impact ≠ TOTAL                        │
│ • Compact Notation: A/N/T or A/Y/P                                     │
│ • Examples:                                                             │
│   - A/N/T: CVE-2024-9380 (Ivanti CSA - requires authentication)       │
│   - A/Y/P: CVE-2024-28995 (SolarWinds - partial impact only)          │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ TRACK (Ongoing Monitoring)                                             │
├─────────────────────────────────────────────────────────────────────────┤
│ • Exploitation: PoC (proof-of-concept code exists)                     │
│ • Priority: Lower urgency than ACT/ATTEND                              │
│ • Action: Monitor for changes in exploitation status                   │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ TRACK* (Defer)                                                          │
├─────────────────────────────────────────────────────────────────────────┤
│ • Exploitation: NONE (no known exploitation)                           │
│ • Priority: Lowest urgency                                             │
│ • Action: Apply patches during normal maintenance windows              │
└─────────────────────────────────────────────────────────────────────────┘

================================================================================
DECISION FACTORS EXPLAINED
================================================================================

1. EXPLOITATION (Primary Factor)
   ─────────────────────────────
   • ACTIVE:  Confirmed in-the-wild exploitation (e.g., detected by EDR/IDS)
   • PoC:     Public proof-of-concept code available
   • NONE:    No known exploitation attempts

2. AUTOMATABLE (Secondary Factor)
   ────────────────────────────────
   • YES:  Exploit can run autonomously (worms, scanners)
   • NO:   Requires human intervention (phishing, social engineering)

3. TECHNICAL IMPACT (Tertiary Factor)
   ───────────────────────────────────
   • TOTAL:    Complete system compromise (RCE, privilege escalation to root)
   • PARTIAL:  Limited access (information disclosure, DoS)

================================================================================

================================================================================
KEY INSIGHT
================================================================================

The 28 "ATTEND" priority KEV CVEs are NOT errors!

CISA KEV inclusion guarantees exploitation='active', but priority tier
depends on the COMBINATION of all three factors:

  ✓ ACT    = active + automatable=yes + impact=total
  ✓ ATTEND = active + (automatable=no OR impact≠total)

Both are valid for actively exploited vulnerabilities, differing only in
remediation urgency based on attack complexity and potential damage.
