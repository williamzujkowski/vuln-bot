Overview

Vuln-Bot is an automated CVE intelligence platform that focuses on high-risk vulnerabilities most likely to be exploited in the wild. Rather than presenting all CVEs (which number in the hundreds of thousands), we apply rigorous filtering to surface only the vulnerabilities that security teams should prioritize.

Data Sources

We aggregate vulnerability data from authoritative sources:

  • CVEProject/cvelistV5 - Official CVE List repository, updated every 7 minutes
  • GitHub Security Advisory Database - Community-driven vulnerability database via GraphQL API
  • FIRST EPSS API - Exploit Prediction Scoring System for probability estimates
  • CISA KEV Catalog - Known Exploited Vulnerabilities actively used in attacks
  • Exploit-DB & Metasploit - Public exploit availability tracking
  • deps.dev API - Package dependency impact analysis for supply chain risk

Prefiltering Logic

We apply a multi-stage filtering pipeline to identify vulnerabilities that warrant immediate attention:

Stage 1: EPSS Threshold (Primary Filter)

Only vulnerabilities with EPSS ≥ 60% are included. The Exploit Prediction Scoring System (EPSS) uses machine learning to estimate the probability of exploitation in the next 30 days. A 60% threshold means we only show CVEs with a high likelihood of being exploited.

Why 60%? Research from FIRST shows that CVEs with EPSS ≥60% account for the majority of actively exploited vulnerabilities while representing only ~3-5% of all published CVEs.

Stage 2: Severity Filter

We focus on Critical and High severity vulnerabilities based on CVSS scores:

  • Critical: CVSS 9.0-10.0 - Exploitable remotely with no user interaction
  • High: CVSS 7.0-8.9 - Significant impact with relatively easy exploitation

Stage 3: Temporal Filter

Currently focusing on 2024-2025 CVEs to surface recent vulnerabilities most relevant to modern infrastructure.

Result

These filters reduce tens of thousands of CVEs down to 297 high-priority vulnerabilities that security teams can realistically review and remediate.

Enrichment Pipeline

Once vulnerabilities pass our filters, we enrich them with additional threat intelligence:

EPSS Percentile Rankings

Flag vulnerabilities in top 1%, 5%, and 10% of EPSS scores for rapid prioritization.

CISA KEV Integration

Cross-reference with CISA's Known Exploited Vulnerabilities catalog. Currently 75 of 297 vulnerabilities are actively exploited according to CISA.

Exploit Availability Detection

Scan multiple exploit databases to flag CVEs with public proof-of-concept code or weaponized exploits.

SSVC Prioritization

Apply Stakeholder-Specific Vulnerability Categorization (SSVC) decision trees:

  • ACT (46 CVEs): Immediate action required
  • ATTEND (89 CVEs): Scheduled remediation
  • TRACK (162 CVEs): Monitor for changes

Risk Scoring

Calculate composite risk scores (0-100) based on CVSS, EPSS, popularity, infrastructure tags, and recency.

Automation & Updates

The entire pipeline is fully automated using GitHub Actions:

  • Scheduled Harvesting: Runs every 4 hours to fetch new CVEs and update EPSS scores
  • Incremental Updates: Default mode processes only CVEs updated in the last 48 hours (~10-20 CVEs per run)
  • Initial Harvest: EPSS-first filtering fetches ~100 CVEs instead of 15,000+
  • Weekly EPSS Refresh: Full rescan recommended to capture score changes
  • Data Validation: Multi-stage validation at ingestion, filtering, enrichment, and publication
  • Automatic Deployment: Changes automatically deployed to GitHub Pages after validation

Quality Gates: All deployments must pass EPSS threshold compliance validation, data quality checks, and post-deployment QA tests before going live.

SSVC Methodology

We use the CISA SSVC (Stakeholder-Specific Vulnerability Categorization) framework to provide context-aware prioritization:

Decision Factors

  • Exploitation: Active, PoC available, or none
  • Automatable: Can the exploit be automated?
  • Technical Impact: Total system compromise or partial?
  • Mission Impact: Effect on organizational operations

Priority Tiers

  • ACT: Patch immediately (within 24-48 hours)
  • ATTEND: Schedule patching (within 30 days)
  • TRACK: Monitor for changes, patch when convenient

Learn more about SSVC at CISA SSVC Guide.

Limitations & Disclaimers

While we strive for accuracy and completeness, users should be aware of the following:

  • EPSS is probabilistic: A 60% EPSS score means 60% probability, not certainty
  • False negatives possible: Some exploited CVEs may have EPSS <60% initially
  • Temporal focus: Older CVEs (pre-2024) may be excluded even if still relevant
  • Not a replacement for comprehensive scanning: This is a threat intelligence feed, not a vulnerability scanner
  • No warranty: Data provided "as-is" without guarantees of accuracy or completeness

Recommendation: Use Vuln-Bot as part of a defense-in-depth strategy combining comprehensive vulnerability scanning, asset inventory, threat intelligence feeds, and security monitoring.

Technical Implementation

Vuln-Bot is built as a static site generator with a Python backend:

  • Frontend: Alpine.js + Tailwind CSS for reactive UI with system dark/light mode
  • Backend: Python scripts for data harvesting, filtering, and enrichment
  • Caching: SQLite with 10-day TTL for API responses
  • Deployment: GitHub Pages with automated CI/CD
  • Testing: Playwright E2E tests for live site validation

The project is open source: williamzujkowski/vuln-bot
